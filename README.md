## Описание проекта

Данный репозиторий содержит исходники проекта и продуктовые артефакты по разработке стратегии монетизации для сервиса планирования питания.

## Структура проекта

- **Корень** - основные продуктовые артефакты (decision.md, onepager.md и др.)
- **`scripts/`** - скрипты для анализа и моделирования
- **`source/`** - визуализации, графики и результаты выполнения скриптов
